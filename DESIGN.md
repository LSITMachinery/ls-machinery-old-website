# LS Smart Machinery design reference

This records the LS-specific application of the homepage direction approved on 16 October 2026. Existing LS branding and business requirements take precedence over community references.

## Reference principles

The inspected awesome-design-md IBM reference informs disciplined information hierarchy, an orderly grid and clear action states. The DJI reference informs named product imagery and the progression from equipment overview to details. Neither reference supplies LS's colours, fonts, content or claims.

## Identity and tokens

Use the existing LS logo and DM Sans. `styles/tokens.css` owns shared colours and homepage semantic aliases: charcoal text, white/warm-neutral surfaces, LS orange for primary actions and a darker orange for readable accent text. Existing non-home token values remain compatible. Keep surfaces open and restrained; use rules and spacing rather than repeated boxed cards.

## Homepage composition

An editorial split hero places the editable proposition and two useful actions beside the selected genuine machine. A visible product link names that machine. Early source-backed client proof precedes six food pathways. A compact equipment directory and model search support returning buyers. Four linked service stages explain planning, machinery, installation/training and support. Existing customer-segment controls and editable company content remain available, with one gallery rather than repeated news/people sections. The final invitation retains the existing email/WhatsApp and form paths.

## Type, layout and imagery

Use a fluid display scale with a wide heading measure, 16–18px body type, balanced headings and clear paragraph lengths. Desktop uses an asymmetric content grid; tablet and mobile stack in reading order. Machine imagery uses contain and intrinsic proportions. Food and site photographs may use deliberate cover crops. No generated machinery illustrations or invented proof.

## Interaction

Default content remains visible. Use 140–220ms feedback for deliberate controls, fine-pointer-only image hover, clear active/focus states and no decorative continuous motion. Honour both reduced-motion preference and the site's pause control. Native links/forms and existing keyboard accordions remain the functional base.

## Boundaries

This is a homepage redesign in the existing architecture, not a Next.js migration or CMS/API replacement. Preserve metadata, catalogue records and handoff semantics. Unknown product facts and unconfigured delivery remain explicit dependencies.
