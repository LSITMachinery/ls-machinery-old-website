## Suggested implementation safeguards

- Preserve LS information while aligning footer/newsletter/contact content to the same page gutters.
- Move social icons into the shared footer and remove the duplicate standalone homepage social block.
- Newsletter action should clearly prepare a subscription request until there is a real subscription service; never claim enrollment without delivery.
- The user now prefers menu products vertically below the selected machinery category; retain five categories and three featured products, but remove the five-column featured-product row.
- Keep catalogue pagination but present feature-led editorial sections, compact process groups and a clear complete equipment index, rather than uniform retail tiles.
- Use only authentic source-backed product imagery, supported technical records and factual project descriptions. The new recordings contain no additional LS technical specifications or verifiable customer quotations.
- Global map should communicate Malaysia base and contact/market direction without inventing overseas offices.
