2. Refactor homepage composition into reusable render functions, preserving CMS field and interaction hooks.
3. Replace homepage layout styles with semantic tokens and responsive components; compact homepage navigation independently.
4. Retain food/category/model-search routes, contextual enquiry handoffs and service paths. Improve keyboard route orientation and correct stale history-link destinations.
5. Build CSS and the homepage snapshot, then inspect desktop/tablet/mobile in one visual pass. Complete at most three refinement passes.
6. Run focused homepage journeys, existing route/catalogue/CMS/enquiry suites, syntax/style checks and the generated-page build. Update only obsolete visual assertions when the approved composition deliberately changes them.
7. Deliver screenshots, baseline comparisons and a verification report with unresolved content/production dependencies. Do not deploy.

No framework migration, catalogue data changes, real enquiry submissions or provider configuration are included. The user has already approved the design scope; the prior audit and present instruction supply the product and design decisions.
